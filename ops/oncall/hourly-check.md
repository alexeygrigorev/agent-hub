# oncall-engineer hourly check

Run for every Hub scheduled prompt or explicit manual check. The schedule is attached to `oncall-engineer` and does not depend on the session engine. Use `HUB_CONFIG_FILE=$HOME/.config/agent-hub/cli.json` for `hub` (`host.json` does not exist on Hetzner; human `hub auth login` done 2026-10-27, so `hub quota` / `hub engines` work).
0. `~/.local/share/agent-hub-ops/session-ctl.sh oncall skills-sync`; read `~/tmp/agent-reports/oncall/handoff.md` if newer than your start; drain `inbox/`; check context (<15% => handoff-restart).
1. For each open alert (from inbox or earlier ticks): re-verify live state (health endpoints, `gh run list`, Hub). Classify real / noise / drill / test leak; start fixers for real ones per CLAUDE.md; forward nothing to people.
2. Write `latest.md` (UTC timestamp even when quiet: "no alerts") and `NEEDS_ALEXEY.md`; copy to `history/`.
   - Never put DataOps/dapier access in `NEEDS_ALEXEY.md` (Alexey's rule t3406u: never ask Alexey for DataOps access). A `blocked_credential`, "Refresh token family revoked", `dataops whoami` or `dapier auth status` failure, or a principal-ping about one, is an infrastructure fault owned by Developer: re-verify as the host user (`dataops whoami`, `dapier auth status`), then start a Developer fix intake (fix-on-failure) or `hub msg` Developer with the intake id and exact error. Follow the CLAUDE.md section "DataOps / dapier credential blockers". Remove any such entry you find in `NEEDS_ALEXEY.md`.
