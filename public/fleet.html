Usage / Quota

Provider-native usage per shared account pool and per host: fresh, stale, exhausted, unavailable or unknown. A passed reset alone never implies recovered capacity.

Alerts

Opened when a machine, session, hub agent or check enters a problem state; resolved automatically on recovery.

Machines and subscriptions

Shared account labels share capacity across machines. Unknown data is not zero usage.

Live aplexer sessions

Reported by each machine; see Heartbeats and liveness for whether each session is working.

Host health and resource utilization

CPU load averages (1m, 5m, 15m), memory utilization (used, available, total), and observation freshness.

Disk space monitoring

Filesystem usage, thresholds (≥85% warn, ≥95% critical), top space consumers, and daily growth trends.

Heartbeats and liveness

Machines: online, stale, offline. Agents: working, idle, stalled (working with no terminal activity), or unknown when their machine is silent.
